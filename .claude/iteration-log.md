## 迭代1

**目标**: 文案科学化 —— 去除AI生成味道，保持专业引导语调

### 文案变更

| 位置 | 旧文 | 新文 |
|------|------|------|
| 顶部副标题 | `CAMPUS MUTUAL AID` | `南大校园 · 免费互助` |
| 发布页说明 | `提交后进入人工审核，审核通过才会展示` | `提交后将进行内容确认，通过后公开展示` |
| 发布须知 | `支持低风险应急耗材...药品仅使用笼统分类` | `本平台仅支持...药品按大类选择即可，无需填写具体药名；处方药与管制药品禁止发布` |
| 类型提示-耗材 | `耗材无需选择细分类...` | `适用于创可贴、碘伏棉签、口罩、消毒用品等低风险应急物品，无需细分品类` |
| 类型提示-药品 | `药品只允许非处方常见药品笼统分类...` | `药品仅限非处方常见药品，按大类选择即可。禁止处方药、管制药品及任何收费转让` |
| 类型提示-工具 | `适用于锤子...偶发需求但不常备` | `适用于偶尔需要但不常备的小工具...建议注明是借用还是赠送` |
| 免责勾选 | `我确认本次发布为免费互助，禁止处方药...` | `我确认本次为免费共享，不含处方药、管制药品及任何形式的收费` |
| 详情公告 | `免费互助信息撮合...` | `本平台仅提供信息匹配，不涉及物品流转。领取前请自行确认包装完好...` |
| 联系方式说明 | `为防止联系方式滥用和隐私泄露...` | `为保护每位同学的隐私，每日查看次数设有上限` |
| 空描述占位 | `发布者暂未填写补充说明。` | `暂未填写补充信息` |
| 页脚版本号 | `版本 0.3.0` | `南大校园互助平台` |

### 功能变更
- **搜索实时响应**: 300ms 防抖输入即搜索
- **Toast 通知系统**: 替代 alert() 弹窗，右上角展示错误/成功消息
- **联系方式剩余次数**: 按钮上直接显示今日剩余次数

### 对抗评审摘要
- **Agent A (用户视角)**: 登录流程过长 (17步), 应隐藏登出状态的发布表单, 联系方式剩余次数应前置
- **Agent B (专业UX)**: 10项改进建议，前5项可在40分钟内完成，包括 toast、布局偏移修复、搜索防抖、筛选提示、ARIA

## 迭代2

**目标**: 发布体验优化 + 日期选择器 + 骨架屏 + 登出引导

### 功能变更
1. **发布页登出引导**: 未登录时不显示完整表单，展示引导卡片（"登录后即可发布" + 去登录/先逛逛按钮）
2. **日期选择器**: 三段下拉 → 原生 `<input type="date">` + `min` 属性防止选择过去日期
3. **骨架屏**: "正在加载..." → 3张动画骨架卡片
4. **发布成功确认**: 发布后展示确认卡片（含物品标题 + 查看我的发布/继续发布按钮）
5. **个人卡片优化**: 游客模式 → 欢迎来访

### 代码变更量
- `web/index.html`: +40/-30 行 (guest卡片、成功卡片、日期输入)
- `web/app.js`: +120/-70 行 (syncPublishView、CTA按钮、骨架屏、日期简化)
- `web/styles.css`: +50/-25 行 (骨架屏动画、toast、guest图标、日期简化)
