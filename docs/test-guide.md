# NanE 南易验收测试指南

这份指南用于测试当前 NanE 网页端、API、管理后台和核心业务闭环。测试者不需要技术背景，按步骤操作并记录结果即可。

## 0. 测试范围

当前主测入口是网页版：

| 入口 | 地址 | 用途 |
|------|------|------|
| 网页端 | https://nane.zylatent.com | 游客浏览、邮箱登录、发布、查看联系方式、我的发布 |
| 管理后台 | https://nane.zylatent.com/admin | 审核、驳回、下架、查看统计 |
| API 健康检查 | https://api.zylatent.com/api/health | 确认后端在线 |

微信小程序端文件仍保留，但小程序备案未完成前不作为主要验收入口。

## 1. 测试前准备

请项目负责人准备：

- 两个南京大学学生邮箱测试账号，均为 `@smail.nju.edu.cn` 后缀。
- 一个管理员账号和密码。
- 至少一个可用于测试的微信号或 QQ 号。
- 能访问测试邮箱收件箱。

建议使用 Chrome 或 Edge。领取确认流程需要两个普通账号，建议一个作为发布者，一个作为领取者。

## 2. 基础可用性

步骤：

1. 打开 `https://api.zylatent.com/api/health`。
2. 打开 `https://nane.zylatent.com`。
3. 刷新页面一次。

验收：

- [ ] API 健康检查返回 `ok: true`。
- [ ] 网页端能正常打开，无白屏。
- [ ] 首页能显示物品列表或明确的空状态。
- [ ] 页面在桌面宽度和手机窄屏宽度下没有明显横向溢出。

## 3. 游客流程

步骤：

1. 不登录，打开首页。
2. 搜索一个关键词，例如“创可贴”或“感冒药”。
3. 点击任意物品卡片进入详情。
4. 点击“查看联系方式”。

验收：

- [ ] 游客能浏览首页公开物品。
- [ ] 游客能查看详情公开信息。
- [ ] 首页和详情只显示到校区、楼栋，不显示宿舍号。
- [ ] 游客不能直接看到微信或 QQ。
- [ ] 点击查看联系方式时有登录或补全资料提示。

## 4. 邮箱登录与用户协议

步骤：

1. 进入”我的”或点击需要登录的操作。
2. 确认登录区默认展示邮箱登录的”验证码登录”tab。
3. 查看用户协议链接，勾选同意。
4. 输入邮箱前缀，确认页面固定显示 `@smail.nju.edu.cn` 后缀。
5. 点击”发送验证码”。
6. 到邮箱查收验证码。
7. 输入验证码并登录。
8. 尝试错误验证码。

验收：

- [ ] 未勾选用户协议时不能发送验证码或登录。
- [ ] 邮箱后缀固定为 `@smail.nju.edu.cn`，不能使用其他邮箱后缀。
- [ ] 正确验证码能登录。
- [ ] 错误验证码有明确失败提示。
- [ ] 验证码邮件能正常收到，必要时检查垃圾邮件。
- [ ] 登录后页面显示当前账号状态。
- [ ] 首次邮箱验证码登录后，提示设置密码。

## 4.5. 密码登录与找回

步骤：

1. 进入”我的”，切换到”密码登录”tab。
2. 输入未注册的邮箱前缀和任意密码，确认登录失败。
3. 使用已设置密码的账号，输入邮箱前缀和正确密码。
4. 确认登录成功。
5. 使用错误密码登录，确认返回”账号或密码错误”（不泄露账号是否存在）。
6. 点击”忘记密码？”进入重置流程。
7. 输入邮箱前缀，点击发送验证码。
8. 输入验证码和新密码（至少 8 位，含字母和数字）。
9. 使用过短、纯数字、纯字母等弱密码确认被拒绝。
10. 重置成功后使用新密码登录。

验收：

- [ ] 密码登录支持 `@smail.nju.edu.cn` 后缀账号。
- [ ] 正确密码能登录并返回 NanE JWT。
- [ ] 错误密码返回统一错误提示，不区分账号不存在还是密码错误。
- [ ] 密码规则：至少 8 位、最多 64 位、必须含字母和数字。
- [ ] 忘记密码可发送验证码并重设密码。
- [ ] 非 `@smail.nju.edu.cn` 邮箱被拒绝。
- [ ] 密码登录登录后仍通过用户协议与资料完整性检查。

## 5. 账号资料

步骤：

1. 登录后进入“我的”。
2. 修改昵称。
3. 设置校区、楼栋、宿舍号。
4. 保存资料。
5. 刷新页面后再次查看。

验收：

- [ ] 昵称可以修改，不默认暴露邮箱前缀。
- [ ] 校区和楼栋为必填。
- [ ] 宿舍号可选。
- [ ] 保存后刷新仍保留。
- [ ] 未补全校区和楼栋时，不能发布或查看联系方式。

## 6. 发布物品

步骤：

1. 使用发布者账号登录并补全账号资料。
2. 进入发布页。
3. 选择“耗材”，填写创可贴等测试物品。
4. 勾选“使用账号对应楼栋及宿舍号”。
5. 填写微信或 QQ，至少一个。
6. 勾选免费互助声明并提交。
7. 再测试“药品”类型，分类选择“感冒药 / 退烧药 / 过敏药”等笼统分类。

验收：

- [ ] 微信和 QQ 至少填写一个，否则不能提交。
- [ ] 未勾选免费互助声明不能提交。
- [ ] 耗材可选择长期有效 / 无保质期。
- [ ] 药品必须填写有效期，不能长期有效。
- [ ] 耗材无需选择细分类，后端默认保存为 `应急耗材`。
- [ ] 药品只能选择非处方常见笼统分类。
- [ ] 提交后物品状态为“审核中”。
- [ ] 新发布物品在审核前不会出现在首页。
- [ ] 发布者在“我的发布”能看到自己填写的宿舍号。

## 7. 管理后台审核

步骤：

1. 打开 `https://nane.zylatent.com/admin`。
2. 使用管理员账号登录。
3. 查看待审核列表。
4. 对测试物品分别执行通过、驳回、下架。
5. 回到普通用户页面刷新。

验收：

- [ ] 管理员能看到待审核物品。
- [ ] 管理员能看到发布者联系方式和宿舍号。
- [ ] 通过后，物品进入首页。
- [ ] 驳回后，发布者在“我的发布”看到驳回状态和原因。
- [ ] 下架后，首页不再展示该物品。
- [ ] 后台统计数据随操作变化。

安全要求：

- [ ] 不要在文档或截图中传播真实管理员密码。
- [ ] 管理员密码以服务器 `.env` 中 `ADMIN_PASSWORD` 为准。

## 8. 查看联系方式与每日额度

步骤：

1. 使用领取者账号登录并补全账号资料。
2. 打开一个已上架物品详情。
3. 点击查看联系方式。
4. 重复查看多个物品，直到每日额度耗尽。

验收：

- [ ] 登录且资料完整后能看到微信或 QQ。
- [ ] 今日剩余额度会变化。
- [ ] 每日最多查看 5 次。
- [ ] 超过 5 次后返回明确提示，不能继续查看联系方式。
- [ ] 未登录或资料未补全时不能查看联系方式。

## 9. 领取确认与邮箱提醒

需要两个普通账号：

- A：发布者
- B：领取者

步骤：

1. A 发布一个数量为 1 的测试物品。
2. 管理员审核通过。
3. B 打开该物品详情并查看联系方式。
4. B 点击”我已联系并领取，提醒发布者确认”。
5. A 查看邮箱，确认邮件为 HTML 格式，包含物品信息和”去 NanE 确认领取”按钮。
6. A 点击邮件按钮，确认浏览器打开网站并自动进入”我的”页，且顶部显示待确认领取提醒。
7. A 在顶部提醒区点击”确认领取”。
8. 再做一次”忽略”场景测试（可在卡片内或顶部提醒区操作）。
9. 回到首页确认物品下架或数量更新。

验收：

- [ ] B 点击后页面提示已提醒发布者，或提示已记录领取提醒。
- [ ] A 收到 HTML 邮件，邮件内有”去 NanE 确认领取”按钮。
- [ ] 点击邮件按钮后打开网站并自动进入”我的”页。
- [ ] 如果 A 账号绑定邮箱，A 能收到”NanE 南易领取确认提醒”邮件。
- [ ] 如果 SMTP 临时失败，站内”我的发布”仍能看到领取提醒。
- [ ] A 在”我的发布”顶部能看到”待确认领取提醒”卡片。
- [ ] A 可在顶部提醒区确认或忽略领取。
- [ ] A 点击”确认领取”后，物品数量扣减。
- [ ] 数量扣到 0 后，物品状态变为”已领取”，首页不再显示。
- [ ] A 点击”忽略”后，物品数量不变，提醒不再显示。
- [ ] B 重复点击同一物品领取提醒时，不会无限创建重复待确认提醒。
- [ ] 待确认物品在”我的发布”列表中优先排序在前。

## 10. 隐私与合规

在上述流程中同步检查：

- [ ] 首页和详情不展示宿舍号。
- [ ] 宿舍号只在发布者本人“我的发布”和管理后台出现。
- [ ] 游客无法查看联系方式。
- [ ] 发布页清楚提示免费互助、禁止处方药/管控药、禁止收费交易。
- [ ] 药品类只出现笼统分类，不引导填写具体药品交易信息。
- [ ] 用户协议可以打开阅读。
