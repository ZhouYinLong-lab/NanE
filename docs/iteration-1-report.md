## 四、待改进（进入 Iteration 2）

### 前端体验
1. **登录区域过长**：验证码登录 + 密码登录 + 忘记密码 + 南哪小帮手 + 设置密码共 5 个面板挤在一个卡片内，需要渐进式展示
2. **发布表单长度**：16+ 个表单元素对首次用户有压力，考虑分步或折叠高级选项
3. **个人资料表单默认隐藏**：新用户登录后看不到资料补全表单，需要手动点"修改"
4. **首页缺少欢迎引导**：首次访问的游客没有简短的平台介绍
5. **无草稿保存**：用户填写发布表单后切换页面会丢失所有数据
6. **空状态插图**：home 空状态 SVG 过于抽象，可用更有情感共鸣的插画

### 后端完善
1. **无分页**：物品列表可能随用户增长膨胀，需要 LIMIT/OFFSET
2. **状态过期作为读请求副作用**：每次 GET /api/items 都执行 UPDATE，应改为定时任务
3. **联系方式明文存储**：若数据库泄露，微信/QQ 全部暴露
