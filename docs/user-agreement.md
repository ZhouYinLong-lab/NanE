# NanE 南易用户协议

版本：v1.0

欢迎使用“南易 NanE”校园闲置应急物品分享平台（以下简称“本平台”）。本平台是一个面向南京大学在校学生的校园互助平台。请您在发布或获取物品之前，认真阅读并充分理解本协议的所有条款。您勾选“我已阅读并同意”或使用本平台任何服务即表示您已充分理解并接受本协议的全部内容。

## 一、服务说明

“南易 NanE”是一个基于学生社区的非营利性闲置物品分享平台。本平台旨在为同学们提供一个便利、有益的渠道，以分享那些廉价、为一次性使用而不得不大量购买的物品（如应急药物、碘伏、棉签等），从而避免浪费，并解有突发情况的同学的燃眉之急。

本平台仅提供物品信息的展示与检索服务，不介入用户之间的实际交接、金钱交易或物品使用。发布者与领取者之间的所有互动均需自行协商并承担相应责任。

## 二、用户资格与账户

### 2.1 注册条件

您必须同时满足以下条件方可注册和使用本平台：

1. 拥有有效的南京大学学生邮箱（@smail.nju.edu.cn）或已通过“南哪小帮手”的邮箱认证；
2. 目前为南京大学在读学生；
3. 具备良好的社区互助意愿，无欺诈记录。

### 2.2 账户注册要求

1. 注册成为发布者，必须填写您本人的微信号和/或 QQ 号；
2. 注册时需如实填写您所在校区与居住楼栋，以便于搜索结果优先展示；
3. 每位用户仅可注册一个账号，您应妥善保管您的账号信息，因账号保管不善产生的一切后果由您自行承担。

## 三、物品发布规范

### 3.1 可发布物品种类

本平台仅允许发布廉价、为了一次性使用而不得不大量购买的闲置物品（例如：未拆封的碘伏、棉签、创可贴、非处方类应急药品等）。严禁发布处方药、管制药品、违禁品以及其他有明确管控规定或法律法规禁止流通的物品。本平台对可发布药物采取白名单制，仅限白名单内的非处方药物发布。

### 3.2 发布信息要求

发布物品时，您必须遵守以下规则：

1. 保质期管理：必须确认物品在保质期内。如包装完好，应填写保质期截止日，物品到期将自动下架；如包装已丢失，须填写购买日期，平台将按同类物品大致保质期代为计算并下架。
2. 数量说明：必须如实说明可提供的物品数量。
3. 位置精确：必须将物品存放位置精确到所在校区及楼栋。
4. 信息真实：您应对您发布的物品信息（包括品类、保质期、数量、位置等）的真实性和准确性负全部责任。

### 3.3 审核机制

所有物品发布均需经过平台审核，以确保无违禁品或处方药上传。平台有权在不事先通知的情况下，下架任何我们认为违规、存疑或不恰当的商品信息。

## 四、信息查看与联系

### 4.1 搜索结果与展示

物品搜索结果将优先展示与您同楼栋、同校区的物品。您也可以按照校区、楼栋或物品分类进行筛选查询。

### 4.2 联系方式获取

在物品查看界面，不会直接展示发布者的联系方式。您需要点击明确的“获取联系方式”等确认按钮后才能看到。为防止滥用，平台将限制每位用户每日查看联系方式的次数。

## 五、责任声明与风险提示

请您充分理解并同意以下事项：

### 5.1 平台免责

本平台仅为信息匹配与展示平台。如有金钱交易，请双方自行协商，与本平台无关。物品的质量、安全性、功效由发布者负责，领取者应在领取时自行进行独立判断和检查。因物品交接、使用或金钱往来产生的任何纠纷、损失或伤害，由发布者与领取者双方自行协商解决，本平台不承担任何法律责任。

### 5.2 用户行为责任

您通过本平台发布或领取物品，均基于您个人的独立判断，并独立承担由此可能产生的一切风险和责任。我们强烈建议您：

1. 当面交接物品，以便检查；
2. 谨慎对待金钱交易；
3. 注意个人人身与财物安全。

### 5.3 服务可用性

本平台为校内学生团队运营的公益项目，将尽力保障服务的稳定，但不对服务的不中断、无错误或安全性作出任何保证。

## 六、用户行为规范

使用本平台时，您承诺并保证：

1. 不发布任何违禁品、处方药或法律法规禁止流通的物品；
2. 不发布虚假、过期或质量低劣的物品信息；
3. 不利用本平台从事任何欺诈、骚扰、非法商业活动或其他违法违规行为；
4. 不收集、存储、传播其他用户的联系方式等个人信息用于本平台服务以外的目的；
5. 不得使用自动化工具、脚本等技术手段干扰平台正常运行。

违反上述规定的，平台有权立即封禁您的账号，并保留追究法律责任的权利。

## 七、协议的变更与终止

### 7.1 协议变更

本平台有权根据需要对本协议进行修订。修订后的协议将在平台上公布。您继续使用本平台即表示接受修订后的协议。

### 7.2 账号注销

您可以随时通过平台功能或联系运营方申请注销账号。账号注销后，您的所有个人信息将被删除或匿名化处理。

本平台为学生独立运营的校园项目，与南京大学官方无隶属关系，不代表学校立场。本协议任何条款被认定为无效或不可执行的，不影响其余条款的效力。本协议未尽事宜，按照中华人民共和国相关法律法规处理。
