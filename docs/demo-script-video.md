# NanE 南易视频演示脚本（2-3 分钟）

**用途**：路演 / 答辩 / 项目汇报  
**建议时长**：2 分 30 秒左右  
**录制方式**：网页录屏 + 后期旁白 + 字幕  
**主入口**：`https://nane.zylatent.com`  
**后台入口**：`https://nane.zylatent.com/admin`

一句话讲清楚：

> NanE 南易是南京大学校园应急物品免费互助平台，让宿舍里临时用不完的应急药品和耗材，更快到附近真正需要的同学手里。

本次演示建议使用的物品：

```text
物品类型：药品
分类：过敏药
名称：未拆封过敏药 1 盒
数量：1
有效期：2027-01-20
说明：未拆封，临时过敏应急，同楼栋可自取。领取前请自行确认包装和有效期。
```

也可以替换为更常见的急用场景：`感冒药 1 盒`、`退烧药 1 盒`、`退烧贴 1 片`、`碘伏棉签 1 包`。如果画面里出现“氯雷他定”等具体药名，旁白仍建议统一说“过敏药”这类笼统分类，避免变成具体药品推荐。

## 录制前准备

- 准备两个普通用户：A 发布者、B 领取者。
- 准备一个管理员账号，用于 `/admin` 审核。
- A 和 B 都提前完成邮箱登录，并补全昵称、校区、楼栋。
- 录制时打码：邮箱、验证码、微信、QQ、管理员密码、宿舍号。
- 发布数量填 `1`，方便演示“确认领取后自动下架”。

## 完整旁白稿

```text
在宿舍里，有些东西平时用不上，但真正需要时又很急。比如未拆封的过敏药、感冒药，或者一片退烧贴。

NanE 南易做的就是校园内的免费互助撮合。游客可以先看物品信息，但看不到微信和 QQ，联系方式默认保护起来。

正式使用前，需要用南京大学学生邮箱登录，并同意用户协议。邮箱后缀固定为 @smail.nju.edu.cn，验证码只用来确认校园身份。

登录后补全校区和楼栋。NanE 不用 GPS，而是按楼栋信息排序，优先同楼栋、同宿舍群、同校区。宿舍号可以填，但不会公开展示。

发布时会区分耗材和药品。药品只使用感冒药、退烧药、过敏药这样的笼统分类。平台禁止处方药、管控药和收费交易，所有发布都要先人工审核。

管理员在后台审核内容，确认免费互助、信息完整、没有违规内容。通过后，物品才会出现在首页。

领取者登录后可以查看联系方式。这里保留每日查看额度，是为了减少联系方式被批量查看，保护大家的隐私。

线下联系并拿到物品后，领取者可以提醒发布者确认。发布者会收到邮箱提醒，也能在自己的发布记录里看到请求。

发布者确认后，系统自动扣减数量。这个演示里数量是 1，所以确认后直接归零，物品自动下架。

NanE 只做校园免费互助信息撮合，不做买卖、不做配送，也不提供医疗建议。让用不完的应急物品，更快到真正需要的人手里。
```

## 最小操作清单

1. 首页：打开 `https://nane.zylatent.com`，展示附近物品。
2. 游客详情：点击物品，点击“查看联系方式”，展示需要登录。
3. 邮箱登录：进入“我的”，勾选协议，输入邮箱前缀，发送验证码，输入验证码登录。
4. 账号资料：展示昵称、校区、楼栋，宿舍号选填。
5. 发布物品：选择“药品 / 过敏药”，填写 `未拆封过敏药 1 盒`，数量 `1`，提交审核。
6. 管理审核：进入 `/admin`，找到待审核物品，点击通过。
7. 领取查看：B 用户刷新首页，进入详情，查看联系方式和今日剩余额度。
8. 领取确认：B 点击提醒发布者确认；A 收到邮箱提醒后，在“我的发布”点击确认领取。
9. 自动下架：刷新首页，确认该物品不再展示。

## 录制避坑

- 不要说“小程序已上线”，当前主入口是网页版。
- 不要说“短信提醒”，当前是邮箱提醒。
- 不要说“平台配送”，线下交接由用户自行完成。
- 不要说“提供医疗建议”，药品只做非处方常见笼统分类。
- 所有真实邮箱、验证码、联系方式、管理员密码都要打码。
