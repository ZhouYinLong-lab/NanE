# 微信小程序上线配置清单

## 基础信息

- 小程序名称：NanE 南易
- 服务类目：信息查询
- 简介建议：NanE 南易是面向校园场景的互助信息平台，帮助同学发布和查询闲置应急耗材信息，促进免费互助与资源共享。
- 头像：建议使用绿色系“南”或 NanE 标识。

## 开发设置

- AppID：已写入 `project.config.json`
- request 合法域名：正式发布前配置 `https://你的 API 域名`
- 本地开发：微信开发者工具可勾选“不校验合法域名、TLS 版本以及 HTTPS 证书”
- 生产环境：`miniprogram/config.js` 中将 `env` 改为 `prod`，并填写 HTTPS API 域名。

## 合规表达

统一使用：

- 校园互助信息撮合
- 免费共享
- 闲置应急耗材
- 人工审核
- 禁止处方药/管控药

避免使用：

- 药品交易
- 药品销售
- 医疗服务
- 诊疗
- 用药建议

## 发布前检查

- 后端 `/api/health` 可通过 HTTPS 域名访问。
- 小程序首页、详情、发布、我的发布均可加载。
- 发布后物品进入“审核中”。
- 管理后台通过审核后，小程序首页可看到物品。
- 查看联系方式每日 5 次限制生效。
- 隐私保护指引已提交。
