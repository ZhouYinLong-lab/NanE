# 微信小程序上线配置清单

## 基础信息

- 小程序名称：NanE 南易
- 服务类目：信息查询
- 简介建议：NanE 南易是面向南京大学校园场景的互助信息平台，帮助同学发布和查询应急耗材及非处方常见药品笼统分类信息，促进免费互助与资源共享。
- 头像：建议使用南易 NanE 紫色标识。

## 开发设置

- AppID：已写入 `project.config.json`
- request 合法域名：正式发布前配置 `https://api.zylatent.com`
- 本地开发：微信开发者工具可勾选“不校验合法域名、TLS 版本以及 HTTPS 证书”
- 生产环境：`miniprogram/config.js` 当前为 `prod`，API 为 `https://api.zylatent.com/api`。
- 后端健康检查：`https://api.zylatent.com/api/health`
- 管理后台：`https://nane.zylatent.com/admin`

## 合规表达

统一使用：

- 校园互助信息撮合
- 免费共享
- 应急耗材
- 非处方常见药品笼统分类
- 人工审核
- 禁止处方药/管控药
- 微信或 QQ 用于线下联系，联系方式受限流保护

避免使用：

- 药品交易
- 药品销售
- 医疗服务
- 诊疗
- 用药建议

## 发布前检查

- 后端 `/api/health` 可通过 HTTPS 域名访问。
- 小程序首页、详情、发布、我的发布均可加载。
- 首页按同楼栋、同宿舍群、同校区优先展示。
- 发布耗材无需细分类；发布药品只能选择感冒药、退烧药、过敏药、肠胃药、其他非处方药。
- 发布时微信或 QQ 至少填写一项。
- 发布后物品进入“审核中”。
- 管理后台通过审核后，小程序首页可看到物品。
- 查看联系方式每日 5 次限制生效。
- 隐私保护指引已提交。

## 后续账号系统

当前登录仍为 Demo 链路。正式账号能力建议接入小助手 challenge-code 身份验证，由 NanE 后端保存 API Key 并签发 NanE 自己的登录态；小程序端不直接持有第三方密钥。
