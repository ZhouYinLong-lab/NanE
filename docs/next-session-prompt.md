继续 NanE 前端迭代优化。项目是南大校园免费互助平台（vanilla HTML/CSS/JS + Node.js + PostgreSQL），当前在 `dev` 分支。

## 当前状态

刚完成排版美化（字重全面降级），前端零 JS 报错，所有页面正常渲染。之前还做了：暗色模式对比度修复、按钮 hover 微交互、a11y 聚焦环、Toast 对比度、物品卡片入场动画、骨架屏暗色适配、提交防双击、DEBUG_MODE URL 参数化等。

详细计划见 `docs/iteration-plan-a-e.md`，按推荐顺序执行：

## 迭代 A — 发布表单体验增强
- 字段级内联校验（标题、数量、联系方式、免责声明，红色提示在字段下方而非顶部 message）
- 实时字数统计（标题 /30，描述 /200，超限标红）
- 过期日期智能默认值（药品+365天、耗材+180天、工具自动勾选长期有效）
- 可选：提交前确认摘要弹窗

## 迭代 B — 登录流程精简
- 5 个区域（验证码/密码/忘记密码/设置密码/南哪小帮手）→ 分步渐进式，默认只显示 2 个
- 忘记密码独立流程
- 南哪小帮手默认折叠

## 迭代 C — 空状态与过渡动画
- 空搜索结果、空我的发布、网络错误 → SVG 插画 + 友好文案
- 页面切换淡入淡出、弹窗滑入动画
- 弹窗 `dialog[open]` CSS 动画

## 迭代 D — 响应式深度打磨
- <480px Chips 横向滚动 + 渐变遮罩
- 弹窗全屏模式
- 触摸友好间距

## 迭代 E — 微交互与反馈
- 物品删除淡出动画、领取确认卡片收缩
- 有效期 ≤7 天倒计时视觉提示
- Toast 加图标 + 手动关闭按钮
- 联系方式剩余次数数字翻转

## 执行规则
1. 从 A 开始，每轮迭代一个主题
2. 每轮结束 commit（在 dev 分支）
3. 改完在浏览器实测，确认零报错
4. 五轮全部结束后更新 `docs/frontend-changelog.md`

服务启动命令：确保 Docker Desktop 运行 → `docker start nane-pg` → `npm run dev:api` → 访问 `http://localhost:37878`
