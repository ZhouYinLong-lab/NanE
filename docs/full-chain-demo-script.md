# NanE 南易全链路功能展示脚本

**用途**：项目答辩 / 内测验收 / 功能演示  
**建议时长**：3 分钟左右  
**演示入口**：`https://nane.zylatent.com`  
**管理后台**：`https://nane.zylatent.com/admin`  
**演示目标**：证明 NanE 已打通“游客浏览 → 校园邮箱登录 → 补全楼栋资料 → 发布 → 管理审核 → 领取查看 → 发布者确认 → 自动下架/删除”的完整闭环。

## 一句话介绍

NanE 南易是南京大学校园应急物品免费互助平台，让同学宿舍里临时用不完的应急耗材、非处方常见药品和工具，更快到附近真正需要的人手里。

## 演示前准备

- 准备两个普通账号：
  - A：发布者账号
  - B：领取者账号
- 准备一个管理员账号，用于后台审核。
- A 和 B 都提前完成南京大学学生邮箱登录，或至少保证能收到邮箱验证码。
- A 和 B 都补全昵称、校区、楼栋；宿舍号可填但录制时打码。
- 发布演示建议使用数量 `1`，方便展示确认领取后自动下架。
- 录屏时打码：邮箱验证码、微信、QQ、宿舍号、管理员密码。
- 如需展示“已领取后自动下架”，请确保演示物品审核通过后数量仍为 `1`。

```text
物品类型：药品
药品分类：过敏药
物品名称：未拆封过敏药 1 盒
数量：1
有效期：2027-01-20
补充说明：未拆封，临时过敏应急，同楼栋可自取。领取前请自行确认包装和有效期。
联系方式：演示微信或 QQ
```

备用场景：

```text
耗材：退烧贴 1 片、碘伏棉签 1 包、创可贴 8 片
药品：感冒药 1 盒、退烧药 1 盒、过敏药 1 盒
工具：镊子、热熔胶枪、螺丝刀
```

## 完整旁白稿

```text
这是 NanE 南易，一个面向南京大学宿舍场景的免费互助平台。它解决的是很小但很真实的问题：急用一片退烧贴、一盒过敏药，或者临时借个工具，不一定非要跑很远去买。

游客可以浏览物品信息，但不能直接看到微信或 QQ。联系方式只有完成校园邮箱登录，并补全楼栋资料后才能查看，这样可以减少隐私泄露和无关打扰。

NanE 首选南京大学学生邮箱登录，只支持 @smail.nju.edu.cn。登录前需要同意用户协议，验证码用于确认校园身份；设置密码后，下次也可以直接密码登录。

登录后需要补全校区和楼栋。平台不使用 GPS，而是根据楼栋做推荐：同楼栋优先，其次同宿舍群、同校区。宿舍号只给本人和管理员看，不会公开展示。

发布时分为耗材、药品和工具。药品只使用感冒药、退烧药、过敏药这样的笼统分类，不鼓励写成具体药品推荐。所有物品都必须免费互助，禁止处方药、管控药和收费交易。

发布后不会立刻上架，而是进入人工审核。管理员确认信息完整、符合免费互助和合规要求后，物品才会出现在首页。

审核通过后，网页端立即读取同一份后端数据。领取者登录后可以查看联系方式，系统会记录查看行为，用于隐私保护和异常排查。

线下联系并实际领取后，领取者可以提醒发布者确认。重复提醒会被拦住，避免打扰发布者；这个动作不会直接修改库存，而是等待发布者确认。

发布者登录后会看到领取提醒。确认后，系统自动扣减数量。演示里数量是 1，所以确认后会自动归零并下架。

下架后的物品不会再出现在首页。发布者也可以在“我的发布”里编辑记录，或者用红色删除按钮隐藏自己的发布记录，但后台仍保留必要的审核和追溯信息。

账号设置里可以管理资料、通知邮件、深色模式和用户协议。NanE 目前以网页版为主，后续可以继续复用同一套 API 做小程序或桌面端。

NanE 不做买卖、不做配送，也不提供医疗建议。它只是让校园里的应急物品，在真正需要的时候，更快、更近地被找到。
```

## 操作清单

1. 首页游客浏览：
   - 打开 `https://nane.zylatent.com`
   - 搜索或筛选物品
   - 点进详情，尝试查看联系方式

2. 邮箱登录：
   - 打开“我的”
   - 勾选用户协议
   - 输入邮箱前缀，发送验证码
   - 输入验证码登录
   - 可展示密码登录 tab 和忘记密码入口，但不必完整演示

3. 补全资料：
   - 进入“账号设置”
   - 修改昵称
   - 选择校区、楼栋
   - 宿舍号选填并打码

4. 发布物品：
   - 类型选择“药品”
   - 分类选择“过敏药”
   - 填写数量 `1`
   - 选择有效期
   - 填写说明和联系方式
   - 勾选免费互助声明并提交

5. 管理审核：
   - 打开 `/admin`
   - 登录管理员
   - 在待审核中找到新物品
   - 点击通过

6. 领取者查看：
   - B 账号刷新首页
   - 进入详情
   - 查看联系方式
   - 点击“我已联系并领取，提醒发布者确认”

7. 发布者确认：
   - A 账号进入“我的发布”
   - 查看领取提醒
   - 点击确认领取
   - 回到首页确认物品消失

8. 发布记录管理：
   - 打开“我的发布”
   - 展示“编辑”
   - 展示红色“删除”
   - 说明删除是发布者侧隐藏，后台仍可追溯

9. 账号设置：
   - 展示账号、通知、外观、协议入口
   - 切换深色模式

## 录制注意事项

- 不要展示真实验证码、微信、QQ、管理员密码和宿舍号。
- 不要说“小程序已上线”，目前主展示形态是网页版。
- 不要说“平台卖药”或“平台配送”，NanE 是免费互助信息撮合。
- 不要说“医疗建议”，药品只使用非处方常见笼统分类。
- 如果使用具体药名做画面示例，旁白仍建议说“过敏药、感冒药”这类笼统分类。
- 发布数量建议填 `1`，方便演示领取确认后自动下架。
- 不要再讲“每日 5 次查看额度”；当前版本已取消每日额度限制。可以说“系统记录查看行为用于隐私保护和异常排查”。
