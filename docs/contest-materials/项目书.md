# NanE 南易校园互助平台

**EL 智能应用开发与创新大赛 · 交互组**

---

## 一、项目背景

### 1.1 痛点来源

大学宿舍里有一类特殊的浪费——"应急凑数购买"。碘伏、棉签、退烧贴、创可贴、剪刀、充电宝……这些物品往往因为一次突发需求被大量买入，用完寥寥几个后便长期闲置，最终悄悄过期或成为搬家时的负担。

与此同时，另一个宿舍里的同学正在深夜因发烧找不到退烧药而焦虑，或因为找不到剪刀要跑去便利店。

这两种场景同时存在于同一栋宿舍楼，却彼此不知。

### 1.2 现有方案的不足

- **宿舍群 / 朋友圈求助**：信息扩散范围有限，响应慢，无法持续沉淀，下次有需要仍要重复求助
- **二手平台（闲鱼等）**：面向大众、非校园场景，药品类发布受限，陌生人信任成本高
- **校园表白墙 / 论坛**：非结构化，无法检索，信息一次性消耗

南大目前没有专门面向校内应急耗材与工具共享、以"同楼栋优先"为核心逻辑的轻量平台。

## 二、项目简介

**项目名称**：NanE 南易校园互助平台

**一句话描述**：一个让南大同学把闲置应急耗材、工具和非处方常见药品免费共享给有需要的同学的校园互助平台，智能匹配同楼栋、同宿舍群、同校区的最近资源。

**线上地址**：https://nane.zylatent.com（已上线，可实时访问）

**核心定位**：
- **物品范围**：应急耗材（创可贴、碘伏、防护用品等）、常用工具（剪刀、充电宝、针线等）、非处方常见药品笼统分类（感冒药、退烧药、过敏药等）
- **服务对象**：南京大学在校学生
- **核心价值**：减少浪费、应急互助、构建校园近邻信任网络

## 三、核心功能设计

### 3.1 发布物品

**三类准入物品**

| 类型 | 说明 | 有效期要求 |
|------|------|------|
| 耗材 | 创可贴、碘伏棉签、口罩等应急消耗品 | 可设长期有效或填写到期日 |
| 工具 | 剪刀、针线、充电宝、工具箱等 | 可设长期有效 |
| 药品 | 仅允许非处方常见笼统分类（感冒药 / 退烧药 / 过敏药 / 肠胃药 / 其他非处方药） | 必须填写到期日，不可设长期有效 |

**安全边界（硬性限制）**：
- 处方药、管控药、来源不明物品一律拒绝上架
- 所有药品分类仅允许笼统描述，不引导填写具体品牌或成分
- 全平台禁止任何形式的收费交易，发布时须勾选免费互助声明
- 所有发布内容进入人工审核队列，审核通过后方可上架

### 3.2 智能近邻排序

平台基于用户注册时填写的楼栋信息和宿舍群规则，对首页物品进行分层排序：

1. **同楼栋**优先展示
2. **同宿舍群**（同片区几栋楼）其次
3. **同校区**再次
4. **跨校区**最后

排序逻辑不依赖 GPS 定位，通过离散化的楼栋映射表实现，保护用户隐私的同时提供"近邻优先"体验。支持仙林、苏州和浦口三个校区。

### 3.3 用户账户与身份认证

平台接入南大校园身份体系，确保用户为在校学生：

- **邮箱验证码登录**：@smail.nju.edu.cn 学生邮箱发送 6 位验证码，验证后签发 NanE JWT
- **Nanna（南哪小帮手）OAuth**：接入南大官方小助手身份体系，通过 challenge-code 验证校园身份
- **密码登录**：首次邮箱验证后可设置密码（8～64 位，含字母与数字），支持验证码重置

登录后须补全校区和楼栋信息，方可发布物品或查看联系方式。宿舍号可选填，仅对发布者本人和管理员可见。

### 3.4 领取确认闭环

1. 领取者在物品详情页点击"我已联系并领取，提醒发布者确认"
2. 系统向发布者邮箱发送 HTML 格式提醒邮件，含"去 NanE 确认领取"跳转按钮
3. 发布者在站内"我的发布"顶部提醒区点击**确认领取**，系统自动扣减数量
4. 数量归零后物品自动下架；发布者也可选择**忽略**（数量保持不变）

SMTP 临时不可用时，站内提醒仍正常显示，不影响业务闭环。

### 3.5 隐私与安全设计

- 首页和详情页只展示到校区和楼栋，不暴露宿舍号
- 联系方式（微信 / QQ）仅登录且资料完整的用户可见，默认隐藏
- 发布者本人查看自己的物品时，才显示宿舍号、联系方式及操作入口
- 联系方式查看行为有记录，防止同一物品被重复消耗

### 3.6 设置与个人中心

- **主题切换**：深色 / 浅色模式，本地持久化
- **邮件提醒开关**：可关闭领取确认提醒邮件
- **账号设置**：邮箱账号管理、登出
- **关于页**：平台说明与用户协议

### 3.7 管理后台

内置独立的管理员后台（`/admin`），支持：审核通过 / 驳回 / 下架物品，查看完整发布者信息，查看平台统计数据（用户数、物品数、按状态分布）。驳回时须填写原因，系统通知发布者。

## 四、技术方案

> 平台已完成生产部署，当前可通过 https://nane.zylatent.com 访问网页端。

| 层级 | 技术选型 |
|------|----------|
| **Web 前端**（主端） | 原生 HTML / CSS / JS，SPA 四标签架构，无构建工具 |
| **微信小程序**（辅端） | 微信原生小程序，代码保留，待完成备案后上线 |
| **后端** | Node.js 原生 `http` 模块，单进程约 2000 行，含静态文件服务、用户 API、管理 API |
| **数据库** | PostgreSQL，schema 随启动自动迁移 |
| **认证** | NJU 学生邮箱 OTP + Nanna OAuth + 密码登录，手写 HS256 JWT，三端共用登录态 |
| **部署** | Azure VM（Korea Central）+ Nginx 反向代理 + Let's Encrypt HTTPS + PM2 |
| **域名** | `nane.zylatent.com`（前端 + 管理后台）/ `api.zylatent.com`（API） |

**核心技术亮点**：
- **分层近邻排序**：`server/proximity.js` 维护三校区楼栋-宿舍群映射，返回 `{rank, scope, label}`，不调用任何地图或定位 API
- **保质期生命周期管理**：药品强制填写到期日，定时任务自动将过期物品变为 `expired` 状态并下架
- **安全防御设计**：药品类目白名单 + 人工审核双重过滤，从技术层面阻断处方药/管控药信息流通
- **领取确认机制**：`claim_requests` 表 + HTML 邮件通知 + 站内提醒，形成完整的线下交接确认闭环

## 五、用户使用场景

### 场景一：发布闲置药品

小李买了一盒 20 粒的过敏药，只吃了 2 粒，还剩 18 粒，保质期到 2027 年初。她打开南易，选择物品类型"药品"，分类"过敏药"，填写数量 18 粒、到期年月日，存放位置"鼓楼 XX 楼"，提交审核。管理员次日审核通过，同楼栋有需要的同学就能在首页优先看到这条物品。

### 场景二：应急借用工具

期末考试前，小王要打印材料，临时找不到剪刀。他打开南易搜索"剪刀"，首先出现同楼栋小张发布的一把剪刀，显示存放楼栋和联系 QQ。小王点击查看联系方式，直接发消息确认，5 分钟内借到剪刀，问题解决。

### 场景三：领取确认闭环

小赵发布了一包创可贴，小刘在站内提交了领取提醒。小赵随即收到一封 HTML 格式邮件，内含物品信息和"去 NanE 确认领取"按钮。点击后跳转至"我的发布"页，页面顶部弹出待确认提醒卡片。小赵点击确认，系统扣减数量；数量归零后物品自动下架，不再占用首页展示位。

## 六、项目创新点

1. **楼栋粒度的智能近邻匹配**：不依赖 GPS，通过注册时的楼栋信息实现"近邻优先"排序，兼顾隐私与便利。三校区的宿舍群规则内置于后端，无需用户额外操作，就能获得最相关的搜索结果。

2. **物品安全生命周期管理**：药品强制填写保质期，定时任务自动到期下架，从技术层面防止过期药品信息继续流通。这是通用二手平台所不具备的垂直安全设计。

3. **白名单 + 人工双重审核**：药品分类仅允许 5 个非处方笼统类目，配合人工审核，从根本上阻断处方药和管控药信息，区别于完全依赖用户自律的普通平台。

4. **完整领取确认闭环**：从"查看联系方式"到"线下交接成功"，平台通过 HTML 邮件 + 站内提醒形成全链路追踪，发布者可主动确认，数量和状态自动更新，不留信息黑洞。

5. **多通道校园身份验证**：NJU 学生邮箱 OTP 和 Nanna OAuth 双通道，后端统一签发 NanE JWT，Web 端、小程序共享登录态。身份验证与业务逻辑彻底解耦，后续扩展端无需改动认证流程。

6. **零依赖轻量工程**：后端仅依赖 `pg` 和 Font Awesome，无框架、无 ORM、无构建步骤，单文件结构清晰，便于后续开源供其他高校参考部署。

## 九、未来拓展方向

平台完成冷启动后，计划从"应急耗材互助"向"全品类闲置免费共享"演进：

- **图书教材**：学期末大量教材闲置，免费流转比定价出售摩擦更低，更符合互助精神
- **文具耗材**：A4 纸、笔芯、订书钉等买多用不完，适合定量发布，按需认领
- **免费周边**：社团活动、比赛赞助产生的贴纸、徽章、文化衫，对持有者已无价值，对感兴趣的同学却有意义
- **开源分发**：若南大各校区验证模型可行，愿意将平台架构开源，供其他高校参考部署，让"校园免费互助"的理念跨越围墙传播
