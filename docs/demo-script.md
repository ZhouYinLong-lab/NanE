# NanE 南易演示脚本

## 1. 首页发现

打开小程序首页，展示 NanE 的核心定位：校园互助信息撮合、免费共享、同楼栋和临近宿舍群优先。

演示点：

- 搜索“创可贴”或“感冒药”
- 切换“耗材”或“非处方药品”筛选
- 说明推荐排序为同楼栋 > 同宿舍群 > 同校区 > 其他校区
- 说明首页只展示审核通过的 `online` 物品

## 2. 物品详情与联系方式限制

进入任意物品详情页。

演示点：

- 位置、有效期、发布者信息
- 风险提示：免费互助、药品仅限非处方常见分类、禁止处方药/管控药、自行判断风险
- 点击“我要领取，查看联系方式”
- 说明后端会记录 `contact_views`，每日最多 5 次

## 3. 发布互助

进入发布页，填写一个低风险耗材或非处方常见药品分类。

演示点：

- 物品类型：耗材 / 药品
- 耗材无需细分类，药品使用“感冒药/退烧药/过敏药”等笼统分类
- 选择一个 Font Awesome 物品图标，说明图标仅用于辅助识别
- 微信或 QQ 至少填写一项，用于线下联系
- 有效期格式校验
- 免费互助、禁止处方药/管控药和禁止收费交易声明
- 提交后状态为 `reviewing`

## 4. 管理后台审核

打开：

```text
https://你的 API 域名/admin
```

当前生产后台：

```text
https://nane.zylatent.com/admin
```

演示点：

- 管理员登录
- 查看待审核物品
- 通过或驳回
- 审核动作写入 `review_logs`

## 5. 数据同步

审核通过后回到小程序首页刷新。

演示点：

- 小程序、服务器 API、管理后台共用 PostgreSQL
- 后台审核后，小程序立即读取同一份数据

## 6. 后续账号与多端路线

简短说明：

- 当前 Demo 登录已能打通发布、审核和展示链路。
- 下一阶段接入南哪小帮手 challenge-code 身份验证，NanE 后端验证后签发自己的 JWT。
- 产品先上线微信小程序，再扩展 Web 站点和 Tauri/EXE 桌面端，仍然共用同一套 API 和数据库。
