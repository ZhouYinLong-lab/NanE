# NanE 南易演示脚本

## 1. 首页发现

打开小程序首页，展示 NanE 的核心定位：校园互助信息撮合、免费共享、同楼栋优先。

演示点：

- 搜索“创可贴”
- 切换分类“消毒护理”
- 说明首页只展示审核通过的 `online` 物品

## 2. 物品详情与联系方式限制

进入任意物品详情页。

演示点：

- 位置、有效期、发布者信息
- 风险提示：免费互助、禁止处方药/管控药、自行判断风险
- 点击“我要领取，查看联系方式”
- 说明后端会记录 `contact_views`，每日最多 5 次

## 3. 发布互助

进入发布页，填写一个低风险耗材。

演示点：

- 白名单说明
- 有效期格式校验
- 免费互助与禁止处方药声明
- 提交后状态为 `reviewing`

## 4. 管理后台审核

打开：

```text
https://你的 API 域名/admin
```

演示点：

- 管理员登录
- 查看待审核物品
- 通过或驳回
- 审核动作写入 `review_logs`

## 5. 数据同步

审核通过后回到小程序首页刷新。

演示点：

- 小程序、服务器 API、管理后台共用 PostgreSQL
- 后台审核后，小程序立即读取同一份数据
