# NanE 南易隐私保护指引草稿

NanE 南易用于校园互助信息撮合。为提供发布、查询、审核和线下联系能力，我们可能处理以下信息：

- 登录与校园身份标识：当前网页端首选南京大学学生邮箱验证码登录，仅支持 `@smail.nju.edu.cn` 后缀；南哪小帮手作为备用身份验证链路，可能处理 `openid`、基础身份信息、校园/学号摘要等信息，用于确认用户身份和维持登录状态。
- 邮箱验证码与通知：平台会发送登录验证码邮件；当领取者发起领取确认提醒时，如发布者账号绑定邮箱，平台会发送领取确认提醒邮件。
- 联系方式：包括微信号或 QQ 号，用于领取者与发布者线下沟通。
- 校区、楼栋与选填宿舍号：校区与楼栋用于同楼栋/同校区优先展示；宿舍号仅供发布者本人和管理员核对，不向普通领取者公开。
- 发布内容：包括物品名称、物品类型、笼统分类、图标、数量、有效期、位置和说明，用于互助信息展示与人工审核。
- 联系方式查看记录：用于每日查看次数限制和防止信息滥用。
- 领取确认记录：包括领取提醒发起人、物品、数量、处理状态和时间，用于发布者确认领取、扣减数量和自动下架。

我们不会提供物品买卖、医疗诊疗或使用建议。平台仅做校园互助信息撮合，不介入线下交接。药品类仅允许非处方常见笼统分类，禁止处方药、管控药、拆封不明物品和任何收费交易。用户应自行确认物品包装、有效期和适用风险。

我们会尽量减少公开展示的信息：

- 首页和详情页只展示校区与楼栋，不展示宿舍号。
- 联系方式默认隐藏，领取者主动点击后才会调用接口查看。
- 每个用户每日查看联系方式次数有限制。
- 领取确认邮件只用于提醒发布者回到平台处理，不替代线下交接确认。
- 管理员仅为审核、安全和纠纷处理目的查看必要信息。

如需删除或更正个人信息，可通过小程序内反馈渠道联系管理员处理。
