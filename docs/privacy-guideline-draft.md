# NanE 隐私保护指引

版本：v1.0

NanE（南易）是面向南京大学校园的免费互助信息平台。我们深知个人信息的重要性，因此本指引用尽量直白的语言说明平台收集了哪些信息、为什么收集、以及你享有哪些权利。

我们收集的信息都围绕一个目的：让校园里的闲置应急物品更快、更安全地到达附近需要的同学手里。你使用南京大学学生邮箱登录时，我们会记录你的邮箱前缀来发送验证码、确认你的校园身份。如果你通过南哪小帮手认证，平台会在后端代理获取你的 openid 和基础校园信息来完成身份验证——整个过程里，南哪小帮手的密钥只保存在服务器上，前端和代码仓库都不会接触。

登录后你需要补全昵称、校区和楼栋。昵称不要求用真名，随便起一个就好。校区和楼栋是必须的，因为 NanE 的推荐排序靠的就是"同楼栋优先"这个逻辑——我们不依赖 GPS，而是通过你填的楼栋信息把离你最近的物品排在最前面。宿舍号是可选的，填了也仅你自己和管理员能看到，不会展示给其他用户。

发布物品时你需要至少留下微信号或 QQ 号中的一项，方便有需要的同学线下联系你。这两项信息默认是隐藏的。任何用户要查看你的联系方式，都必须先登录并且主动点击"查看联系方式"按钮，每次查看都会被记录下来。平台对每个用户每天能查看联系方式的次数做了限制（最多 5 次），这样做是为了防止有人批量获取大家的联系方式。

发布物品的时候我们还会记录物品名称、类型、分类、数量、有效期、位置和你写的补充说明。所有发布的内容都会先进入人工审核，通过后才会公开到首页。这个审核环节是平台重要的安全护栏——它确保发布内容符合免费互助的定位，不让处方药、管制药品或者收费交易混进来。

除了联系方式的查看记录，平台还会记录领取确认的过程：谁发起了领取提醒、涉及哪个物品、数量多少、处理结果如何。这些记录只用于让发布者确认物品确实被领取了、系统正确扣减数量，以及物品数量归零后自动下架。

我们不会把你的信息用于商业推广，也不会卖给或共享给第三方。你的宿舍号、邮箱地址、联系方式都不会被公开。管理员只有在审核内容、处理纠纷或者安全检查的时候才会查看必要的信息——这不是日常浏览，而是有明确目的的定向查阅。

数据库连接密码、SMTP 授权码、南哪小帮手的 API Key 这类敏感配置只存放在服务器的 .env 文件里，不会进入 Git 仓库，也不会出现在前端代码中。

你随时可以在"我的"页面查看和修改自己的昵称、校区、楼栋、宿舍号和联系方式。如果需要删除某个发布内容或者注销账号，联系管理员即可处理。

我们可能会根据实际情况更新这份隐私指引，更新后的版本会在平台内展示。你继续使用 NanE 就表示你接受了更新后的内容。

本指引目前是草稿版本，正式发布前可能在措辞上做进一步微调。如果你对个人信息处理有任何疑问，欢迎通过 NanE 站内反馈渠道联系我们。
