# NanE 南易隐私保护指引草稿

NanE 南易用于校园互助信息撮合。为提供发布、查询、审核和线下联系能力，我们可能处理以下信息：

- 微信登录标识：用于识别用户身份和维持登录状态。
- 联系方式：包括微信号或 QQ 号，用于领取者与发布者线下沟通。
- 校区、楼栋与选填宿舍号：校区与楼栋用于同楼栋/同校区优先展示；宿舍号仅供发布者本人和管理员核对，不向普通领取者公开。
- 发布内容：包括物品名称、分类、数量、有效期、位置和说明，用于互助信息展示与人工审核。
- 联系方式查看记录：用于每日查看次数限制和防止信息滥用。

我们不会提供物品买卖、医疗诊疗或使用建议。平台仅做校园互助信息撮合，不介入线下交接。用户应自行确认物品包装、有效期和适用风险。

如需删除或更正个人信息，可通过小程序内反馈渠道联系管理员处理。
